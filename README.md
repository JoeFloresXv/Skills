# Skills

Repositorio personal de skills para Codex.

## Carpetas

- `comprobantes`: skill para escribir historias de comprobantes/vouchers de App BIZ, incluyendo flujos de autorizacion, rechazo, multimoneda y variantes de compartir.
- `json-prompt-generator`: skill para convertir imagenes de referencia en prompts JSON estructurados para generadores de imagenes.

## Uso

Cada carpeta contiene su propio `SKILL.md` y, cuando aplica, archivos de apoyo como referencias, plantillas y ejemplos.
